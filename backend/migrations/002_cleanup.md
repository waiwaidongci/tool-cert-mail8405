# 002 班组纠正与清理

计量室登记批次内「外协姓名 → 正确班组」的对应关系后，后台清理改写该批次的原始行、历史班报与导出文件，证书与到期判定不变。清理期间这些批次暂停查看，其他批次照用。应用启动时只补建缺失表，不涉及既有表的字段变更。

- `owner_corrections` 按批次名称保存纠正映射（`dataset_name` + `old_name` 唯一）。导入原文件重传与旧计算写库前同样套用该映射，旧姓名不再入库。
- `cleanup_tasks` 每个数据批次一条，记录清理状态（`cleaning` / `done` / `failed`）、版本号、尝试次数与租约。登记纠正会提升版本并重新打开任务；后台按版本重试，单趟替换保证重试不重复替换。导出 CSV 的旧副本清理完成后任务才标记 `done`，批次随即恢复查看。
